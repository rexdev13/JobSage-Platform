JOBSAGE requests access to Google Calendar so an authorised JOBSAGE marketing user can connect their own writable calendar to the JOBSAGE interview-booking workflow.

The requested scope is:
https://www.googleapis.com/auth/calendar

JOBSAGE uses this access only to:

1. Identify a writable calendar for the connected marketing user.
2. Check free/busy availability before offering interview times.
3. Create a JOBSAGE-managed calendar event with the selected interview time and invited attendees.
4. Create a Google Meet link for that interview.
5. Update or cancel JOBSAGE-managed interview events when the authorised user changes or cancels the booking.

The connection is optional and is initiated by the marketing user from the JOBSAGE Calendar page. JOBSAGE does not use Google Calendar data for advertising, behavioural profiling, credit decisions, or training general-purpose AI models. JOBSAGE does not sell Google Calendar data or transfer it to unrelated third parties.

JOBSAGE stores the OAuth refresh token in encrypted form. It stores only the connected account email, writable calendar identifier/name, connection timestamp, and booking references needed to keep JOBSAGE-managed bookings synchronised. Free/busy information is used to calculate availability and is not used to create an unrelated user profile.

The marketing user can disconnect Google Calendar from JOBSAGE at any time or revoke access through Google Account settings. JOBSAGE's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements:
https://developers.google.com/terms/api-services-user-data-policy

The public privacy policy describing this access is:
https://jobsage.co.uk/privacy
