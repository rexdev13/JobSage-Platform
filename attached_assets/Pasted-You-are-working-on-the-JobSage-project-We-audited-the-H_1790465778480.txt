Do not use the Healthcare CQC script for non-Healthcare sectors.
Do not use CQC for unrelated sectors.
Do not import anything.

Goal:
Prepare non-Healthcare sector enrichment by first identifying exact sector labels, then running capped website/careers pilots for the best launch sectors.

Inputs:
- `.local/reports/sponsor-enrichment/jobsage-sponsor-base-export.csv`
- `.local/reports/sponsor-enrichment/jobsage-company-site-existing.csv`
- `.local/reports/sponsor-enrichment/jobsage-existing-vacancy-sources.csv`

Step 1: Sector inventory
Read the sponsor export and produce a sector count table:
- exact `industry` value
- total sponsors
- count with existing website
- count with existing careers URL
- count with existing ATS/provider fields
- count with existing contact email domain
- count with prior source evidence

Exclude exact `Healthcare`.

Step 2: Choose pilot sectors
Pick up to 5 non-Healthcare sectors with the best launch value and strongest existing signals. Prefer sectors such as:
- Finance
- Technology / Software / Information Technology, if present
- Engineering
- Education
- Hospitality
- Construction
- Social Care, only if it is separate from Healthcare

Use exact `industry` labels from the CSV. Do not invent sector names.

Step 3: Run capped pilots
For each selected sector, process only 50 sponsors first.

For each sponsor:
1. Use existing website first.
2. Use existing careers URL if present.
3. Use contact email domain as a lead.
4. Use known company-site existing file as a lead.
5. Use known vacancy-source file as a lead, but do not accept vacancy URLs as websites without first-party identity checks.
6. Use SponsorList/public sponsor evidence if available.
7. Use optional search only if already configured; if search is not configured, continue without it and report that clearly.
8. Verify the official company website.
9. Try to verify a first-party careers/jobs/vacancies/recruitment page.
10. Keep ATS/job-board findings as separate evidence, not as company website results.

Do not accept:
- generic directories
- Companies House only
- Facebook/LinkedIn only
- old PDFs only
- unrelated recruiters
- ambiguous domains
- directory/search matches without first-party verification

Confidence:
- `high`: official employer website/careers page clearly verified.
- `medium`: likely correct but needs review.
- `low`: weak possible match.
- `unverified`: no reliable source.
