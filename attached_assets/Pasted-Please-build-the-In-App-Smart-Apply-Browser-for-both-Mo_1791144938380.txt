Candidates must be able to click "Smart Apply" and have the application form open inside an embedded in-app browser with a collapsible sidebar/drawer that prefills all fields in one click and auto-tracks submissions—with zero need to install an extension.

Here is the exact implementation specification:

1. Blueprint Code to Reuse from `artifacts/chrome-extension`:

   - `artifacts/chrome-extension/src/components/Sidebar.tsx`: Blueprint for the assistant UI.

2. Backend Application Proxy Route (`artifacts/api-server/src/routes/smartApplyProxy.ts`):
   - Create a secure streaming proxy endpoint: `GET /api/smart-apply/proxy?url=...` (authenticated with candidate session).
   - When given an external apply URL (e.g. from NHS Jobs, Trac, or employer site):
     a) Fetch the external HTML with cookie/session persistence.
     b) Strip headers that block embedding in iframes: remove `X-Frame-Options` and sanitize restrictive `Content-Security-Policy` headers.
     c) Rewrite relative links, stylesheets, scripts, and form action URLs so they route through the proxy.
     d) Inject a lightweight client runtime script `<script src="/smart-apply-inpage-bridge.js"></script>` into the HTML `<head>`.
     e) Forward POST requests from forms back to the destination server through the proxy.

3. Injected In-Page Bridge (`smart-apply-inpage-bridge.js`):
   - Package the logic from `questionDetector.ts`, `prefill.ts`, and `trackerDetector.ts` into a lightweight script.
   - Communicates with the parent JobSage window via `window.postMessage`:

     - On Mobile: Full-screen view with a floating bottom bar ("Smart Apply Assistant") that expands into a bottom drawer with 1-tap prefill and quick-copy chips (NMC/GMC PIN, personal statement).
