## Prompt for Replit

> **Redesign the Visa Sponsoring Employers page to improve usability and automate vacancy management. Remove the "Check Vacancies" button from each employer card. Add a new global button called "Check All Vacancies" immediately to the right of the "Bookmarked" filter. When clicked, it should scan every employer currently in the sponsor database, retrieve vacancies from all configured sources, deduplicate results, calculate a Jobsage suitability score for the logged-in candidate, update the database, refresh the vacancy counts, and display progress with a loading indicator.**
>
> **Replace the old "Check Vacancies" button on each employer card with a dynamic "Match %" indicator showing how well the candidate fits vacancies at that employer. The percentage should be based on the highest-scoring vacancy available. Clicking an employer should display all vacancies sorted from highest suitability to lowest, with eligibility status, missing requirements (if any), and an Apply action.**
>
> **Run the vacancy synchronisation automatically every day using a scheduled background job. During each sync, refresh the UK sponsor register, check all employers for new vacancies, update vacancy counts, recalculate candidate suitability scores, and store the results. The "With Jobsage Vacancies" counter at the top of the page should always reflect the current number of employers that have one or more Jobsage vacancies available after the latest sync, and each employer card should also display its own vacancy count and the timestamp of the most recent successful update.**
>
> **The entire process should be fully automated so that candidates always see fresh vacancies ranked by relevance without needing to manually check each employer.**

This design turns the page into an AI-driven matching engine rather than a simple sponsor directory, which aligns much more closely with Jobsage's goal of presenting only the most relevant opportunities to each candidate.
