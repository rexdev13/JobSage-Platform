PART 2: Universal Open-Text Feedback System (Linear/Vercel Style)
1. Database Schema (lib/db/src/schema/feedback.ts)
Create and export feedbackTable:

id: serial primary key
userId: varchar nullable (references users.id on delete set null)
userEmail: text nullable
category: varchar not null (values: "issue", "idea", "general")
message: text not null (the user's open-ended feedback text — allow full unrestricted text)
pageUrl: text not null (auto-captured current URL at submit time)
userAgent: text nullable
screenResolution: text nullable
status: varchar default "new" (values: "new", "in_review", "resolved")
adminNotes: text nullable
createdAt: timestamp with time zone default now()
Add indexes on category, status, and createdAt.
Generate and run the Drizzle migration.
2. Backend Routes (artifacts/api-server/src/routes/feedback.ts)
POST /api/feedback:
Open to both guests and authenticated users.
Automatically captures req.user?.id and req.user?.email if authenticated.
Validates body with Zod: { category, message: z.string().trim().min(3), pageUrl, userEmail?, screenResolution? }.
Inserts row into feedbackTable and returns { success: true, id: feedback.id }.
GET /api/admin/feedback:
Protected: requireRole(["admin", "super_admin"]).
Supports filters: category, status, page, limit (default 50).
Returns feedback records and counts.
PATCH /api/admin/feedback/:id:
Allows admins to update status ("new" | "in_review" | "resolved") and optional adminNotes.
