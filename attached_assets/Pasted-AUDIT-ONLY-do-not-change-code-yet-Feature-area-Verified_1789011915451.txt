Feature area: Verified employer/sponsor contact discovery for Send CV

Context:
- The Home Office/GOV.UK sponsor register is a compliance dataset (org name, town/city, county, route/sub-route, licence rating). It is NOT a contact directory and has no emails/phones/recruitment contacts.
- Send CV needs a trustworthy recipient email.
- “Apply via Job Board” is separate and uses the vacancy external application URL; do not confuse the two.
- We believe JOBSAGE already has an enrichment path that tries to find published contacts from vacancy fields, employer profiles, official websites, and careers/contact pages, storing source/evidence rather than inventing addresses.

Goal of this audit:
Map exactly what contact enrichment we already have, what it stores, how Send CV is gated, where it fails, and what is missing before any “one-time enrichment” or scraping ideas.
