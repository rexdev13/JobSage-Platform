4. If none, check robots.txt and sitemap.xml for specific job listing URLs.
5. If still nothing, mark unresolved with a reason code.

Rules: run in capped batches (default 200 employers), respect per host pacing, never raise concurrency to go faster, and never mark an employer's source verified unless identity is proven.
