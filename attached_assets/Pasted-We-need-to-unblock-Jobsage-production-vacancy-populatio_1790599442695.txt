  - one production sponsor is clearly stronger than all others
- If multiple production sponsor rows clearly represent the same employer and have blank/non-conflicting URL fields, write/link the same verified URL to all matching blank sponsor rows instead of choosing one arbitrarily.

Task 3: Resolve existing URL conflicts as vacancy sources
For the 312 existing URL conflict rows:
- Normalize URLs before comparing:
  - http vs https
  - www vs non-www
  - trailing slash
  - redirects
  - canonical domain
- Classify each conflict:
  - same after normalization => no-op
  - existing is homepage and candidate is careers/jobs page => keep website, add candidate as careers/source URL
  - existing URL is dead, parked, irrelevant, or redirects badly and candidate is verified official => replace existing
  - both URLs are valid official employer URLs => preserve existing and add candidate as secondary source/staging source
  - candidate is unverifiable or unrelated => manual URL review
  - two unrelated live domains => manual URL review unless one clearly links to the other

Important:
Existing URL conflict should not automatically block vacancy ingestion. If the candidate URL is official and useful, store it as a careers/source/staging URL without overwriting the existing website.

Output:
- url-conflict-noop-normalized.csv
- url-conflict-add-careers-source.csv
- url-conflict-replace-dead-existing.csv
- url-conflict-secondary-source.csv
- url-conflict-manual-review.csv
