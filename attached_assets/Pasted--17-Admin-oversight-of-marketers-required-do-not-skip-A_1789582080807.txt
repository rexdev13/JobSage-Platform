## 17. Admin oversight of marketers (required — do not skip)

Admins/super-admins can see “many things about marketers.” Document ALL of that as its own product surface, not as a footnote on the marketing inbox.

If a screen, field, chart, email, or API exists only for admin looking *at* marketers, it belongs here. Quote paths, copy, payloads. If it does not exist, **not implemented**.

### 17.1 Admin surfaces about marketers

For each, path + file + who can open it + what it shows:

- List of marketing users (name, email, role, active, Calendly URL, assigned-lead counts, last login)
- Create / invite / edit / deactivate / delete a marketer
- Change someone’s role to/from `marketing`
- Impersonate a marketer
- Per-marketer performance (not `my-performance` — admin looking at one or all marketers)
- Leaderboard / comparison of marketers
- Filter leads by assignee (including Unassigned)
- Assign / unassign / bulk-assign from the admin leads page
- Admin calendar: all marketers’ events vs one marketer (`marketingUserId` query)
- Any admin dashboard widgets (today’s claims, unclaimed queue, conversion by marketer)
- Reports / CSV / audit log of marketing actions
- Settings for marketing (default Calendly, notify emails)
