PERFORM A COMPLETE JOBSAGE BUILD-COMPLETENESS AUDIT

Your task is to determine, using direct source-code and test evidence, whether every part of the JOBSAGE web and mobile application has actually been built.

This is an audit first. Do not claim completion based on plans, task cards, comments, screenshots, generated documentation or the existence of components alone.

AUDIT RULES

1. Read both original JOBSAGE specifications completely.
2. Inspect the current authoritative source code, database schema, migrations, APIs, workers, tests, mobile configuration and documentation.
3. Inspect pending, completed and unassigned task cards.
4. Search for:
   - TODO and FIXME comments
   - Placeholder screens
   - “Coming soon” content
   - Mock data
   - Hardcoded success responses
   - Empty handlers
   - Disabled feature flags
   - Unconnected buttons and forms
   - Routes without screens
   - Screens without routes
   - APIs without UI consumers
   - UI actions without working APIs
   - Missing loading, empty and error states
   - Tests that mock away the feature being claimed
5. Do not modify source code during this audit.
6. Do not describe a feature as complete unless its UI, API, database behaviour, permissions and tests are connected.
7. Separate source implementation from physical-device, production-provider and store verification.
8. Do not claim real-device verification from browser previews, automated tests or emulators.
9. Do not claim store readiness without store assets, declarations, signing and review requirements.
10. Never expose credentials or customer data.

Give every requirement exactly one status:

- PARTIALLY BUILT

You may declare the app fully built only if every applicable specification requirement is either:

If any applicable requirement is PARTIALLY BUILT, UI ONLY, BACKEND ONLY, PLACEHOLDER OR MOCK, NOT BUILT or BROKEN, the correct conclusion is:

“JOBSAGE IS NOT FULLY BUILT.”

Do not implement fixes during this audit. Produce the evidence-backed audit first so the remaining work can be assigned precisely.
