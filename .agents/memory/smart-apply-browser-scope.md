---
name: In-app Smart Apply scope
description: User's mobile and desktop no-extension requirement for the Smart Apply browser.
---

The user requested Smart Apply inside the JOBSAGE web app on both mobile and desktop without requiring candidates to install the Chrome extension. The existing extension's detection, safe prefill, and confirmation engines are the requested blueprint.

**Why:** The user explicitly wants a no-install application flow, including candidate-controlled prefill and accurate submission tracking.

**How to apply:** Treat mobile support and removal of the mandatory installation gate as core requirements of the replacement flow. Be explicit about compatibility limits; do not promise universal detection or mark an outbound click as a submitted application.
