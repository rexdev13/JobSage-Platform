name: Candidate alert and Opportunities parity
description: Candidate job-alert emails must use the same visible vacancy gates and ranking as the Opportunities feed.
---
Candidate job-alert emails must select from the candidate-visible Opportunities composition and ranking, then cap the result at five before durable URL deduplication.

**Why:** An independent alert query previously classified roles differently, split eligibility into conflicting email sections, and could send more vacancies than the product feed showed.

**How to apply:** Reuse the same profession mapping, source evidence, liveness, contact/apply route, region, registration/licence, score, and tie-break rules whenever changing candidate alert delivery.
