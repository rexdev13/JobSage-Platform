---
name: Smart Apply desktop-only installation
description: The Chrome extension install and extension-required application flow is for desktop users only.
---

Smart Apply's Chrome extension flow is desktop-only. Mobile and touch-first users should not be sent to the Chrome Web Store or manual ZIP installation, and should not be blocked by an extension-required prompt. Show concise desktop guidance and retain the in-app assisted application path where supported.

**Why:** The owner explicitly confirmed on 26 October 2026 that the extension flow is only for desktop users.

**How to apply:** Keep Store links, ZIP instructions, install nudges, and extension-required gates limited to desktop environments. Test mobile user agents and touch-first layouts so they do not expose unsupported install actions.
