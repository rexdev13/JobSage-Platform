Use the owner-supplied orange-to-burgundy JOBSAGE wordmark and exact tagline “Find work that moves you.” as the current identity.

**Why:** The owner explicitly replaced the older identity and requires both the logo and its subtitle to remain visible without awkward sizing or placement. Shrinking the complete artwork into a compact header makes the embedded tagline too small.

**How to apply:** Preserve the supplied lettering rather than recreating it with a font. In compact application UI, scale a cropped wordmark proportionally and set the tagline as separate readable text; use the original full lockup where space permits. Reuse the existing JOBSAGE J app mark for native mobile icons; do not invent a substitute mark (see `mobile-launch-branding.md`). See `docs/jobsage-logo-guidelines.md` for sources and asset provenance.
