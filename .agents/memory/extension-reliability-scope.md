---
name: Extension reliability and autofill scope
description: Owner-approved functionality must not be narrowed by disclosure-only changes.
---

The owner requires broad autofill for all supported application fields from saved profile and CV evidence, apart from genuinely sensitive disclosures and candidate attestations. Detection, completion indicators and submitted-application tracking are core product requirements, not optional features.

**Why:** A privacy/disclosure update also narrowed field classification and evidence access, reducing the extension's usefulness without an agreed functionality change. The owner explicitly objected.

**How to apply:** Disclosure/copy work must not silently reduce detection, autofill or tracking coverage. Distinguish professional healthcare/financial experience from personal health/banking disclosures. Preserve no-invention and no-auto-submission rules. Verify the complete application journey before claiming reliability; distinguish synthetic browser checks from live employer-site verification.
