---
name: Extension AI disclosure scope
description: Owner decision on the Smart Apply AI notice and consent prompts.
---

Smart Apply should not ask for separate AI-assistance consent. The installation UI should show only “AI is used” below the Chrome Web Store link, without additional AI-notice copy or controls.

**Why:** The owner explicitly requested replacing the consent experience with that short installation notice.

**How to apply:** Keep the extension and API consistent with this decision. Preserve sensitive-field safeguards and factual-only answer rules; removing the consent gate does not authorize invented facts or broader data sharing.
