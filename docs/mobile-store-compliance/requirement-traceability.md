- `attached_assets/Pasted-Build-the-complete-production-JOBSAGE-mobile-app-for-An_1791791086505.txt` — mobile application specification.

This is a live engineering matrix, not a declaration of store, legal or production readiness. The requirements are grouped only where their acceptance evidence is shared; source section numbers keep the groups traceable. “Source” means code/documentation is present, not that the user journey has passed. Device, external-provider, restore and store-console evidence are recorded separately. “Files changed” records changes made while addressing the requirement; pre-existing files are named as evidence, not represented as changed.
